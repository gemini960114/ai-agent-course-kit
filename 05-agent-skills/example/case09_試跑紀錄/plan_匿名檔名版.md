# 政府會議文件盤點報告與分類規劃

本文件為 `example/case09/messy_files/` 內 25 個政府會議文件檔案之內容解析、場次歸屬、類型判定、齊全度比對與分類架構建議。依照指示，**目前僅執行文件內容判讀與規劃，尚未移動或複製任何檔案**。

---

## 一、盤點摘要

- **待整理檔案總數**：25 個檔案
- **涵蓋主要機關**：國家發展委員會（資訊管理處承辦）
- **主要會議主體**：國家發展委員會資料開放諮詢小組會議
- **涉及會議場次**：共 5 場正式會議（106 年第 3 次 ～ 108 年第 2 次）
- **檔案格式分佈**：
  - Word 文件（`.docx`）：11 個
  - PDF 文件（`.pdf`）：8 個
  - PowerPoint 簡報（`.pptx`）：3 個
  - Excel 試算表（`.xlsx`）：1 個
  - OpenDocument 文字（`.odt`）：1 個
  - 逗號分隔文字（`.csv`）：1 個
- **文件類型統計**：
  - 議程（Agenda）：5 份
  - 會議紀錄（Minutes）：5 份
  - 逐字紀錄（Verbatim Transcript）：4 份
  - 簡報（Presentation）：5 份
  - 會議附件／清冊（Attachment）：5 份
  - 非會議資料／開放資料集（Unrelated）：1 份
