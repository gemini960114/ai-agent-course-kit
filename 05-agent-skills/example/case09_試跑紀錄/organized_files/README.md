## 分類邏輯
本資料夾依 `example/case09/plan.md` 盤點結果，將 `messy_files/` 中的政府會議文件依「會議年度/次數」→「文件類型」兩層分類複製過來，原始檔案未修改。

分類層級：
- 第一層：`{年度}第{次}會議_{YYYYMMDD}`，例 `107年度第1次會議_1070507`
- 第二層：`01_議程 / 02_簡報 / 03_議程附件 / 04_會議紀錄 / 05_逐字紀錄`
- 無法判斷歸屬之檔案置於 `_待確認/`

檔案命名規則：`{會議名稱}_{文件類型}.{副檔名}`，例 `107年度第1次會議_議程.docx`
原始檔名保留於 INDEX.md 對照。
