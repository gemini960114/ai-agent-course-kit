## 3. 「CC 授權列為甲類授權選項」這個議題，在各次會議怎麼發展？

- **答案**：
  該議題經歷「提案建議 ➔ 提報行政院小組研商 ➔ 落實並解除列管」三個階段的演進：
  1. **106 年第 3 次會議（106.09.28）｜萌芽與提案**：
     - 林誠夏委員指出文化部數位格式藝術品因屬高度屬人創作，難以適用容許再授權之「政府資料開放授權條款 1.0 版」，建議研議納入創用 CC（如姓名標示、相同方式分享）。
     - 會議決議請資管處研議後提報行政院資料開放諮詢小組會議討論。
  2. **107 年度第 1 次會議（107.05.07）｜提報院級小組研議**：
     - 針對政府資料開放授權條款 1.0 版與創用 CC 條款差異，決議將「指定 CC0、CC BY 或 CC BY-SA 成為甲類授權選項」之議題提報 107 年下半年行政院資料開放諮詢小組會議討論，並評估會前邀集文化部等相關機關及學者專家預先研商。
  3. **107 年度第 2 次會議（107.11.07）｜達成目標並解除列管**：
     - 於歷次會議決議事項辦理情形中確認，「指定 CC0、CC BY 或 CC BY-SA 成為甲類授權選項」已達成當初建議目標，會議決議同意解除列管。
