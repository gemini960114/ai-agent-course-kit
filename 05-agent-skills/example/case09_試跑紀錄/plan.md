命名規則建議：
- 目錄：`{年度}{第X次會議}_{YYYYMMDD}`
- 檔案保留原名，必要時加上前綴標註版本，如 `議程_核定版` 改名為 `107年度第1次會議_議程_核定版.docx`
- 建立 `inventory.csv` 與本 `plan.md` 作為盤點依據，後續整理時以此為對照。
