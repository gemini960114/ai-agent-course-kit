# AI 協作開發與 Agent Skills

> 和 AI 一起寫程式、做研究，用 skill 讓它照你整理好的方法做事，並且學會不盲目相信它。

📖 **教學網站：<https://gemini960114.github.io/ai-skills-course-kit/>**

AI 幾秒鐘就能寫程式、整理文獻、做出網頁和文件，但它也會編造內容、謊報完成。這門課從裝好工具開始，一步步練習：**讓 AI 做事 → 檢查它做的事 → 把做事的方法寫成 skill。**

## 課程地圖

| 階段 | 你會做出 | 你會遇到的 AI 錯誤 | 時間 |
| --- | --- | --- | --- |
| [01 安裝環境](01-install/README.md) | 能和 AI 協作的開發環境 | — | 15～30 分 |
| [02 AI 整理文獻](02-organize-data/README.md) | 一張論文比較表 | 補寫摘要沒有的樣本數和結果 | 30 分 |
| [03 連線 GitHub](03-hello-github/README.md) | 第一個推上 GitHub 的程式 | — | 30 分 |

| [05 Agent Skills](05-agent-skills/README.md) | 產品頁、海報、研究論文、整理好的會議文件，以及自己做的 skill | 照著 skill 做，不代表成果正確 | 2 小時＋課後自學 |
| [06 超級電腦](06-hpc-demo/README.md)（老師示範） | （示範）AI 操作國網中心超級電腦 | 謊報「15/15 完成」、自行修改程式 | 20～30 分 |

## 開始

1. 安裝 AI 編輯器：[01-install/00-antigravity.md](01-install/00-antigravity.md)
2. 取得教材：下載 [ZIP 檔](https://github.com/gemini960114/ai-skills-course-kit/archive/refs/heads/main.zip)，解壓縮到「文件」（資料夾名稱為 `ai-skills-course-kit-main`）。已經裝好 Git 的人也可以用 `git clone https://github.com/gemini960114/ai-skills-course-kit`
3. 用 Antigravity IDE 開啟教材資料夾，安裝模組一～三：[01-install/README.md](01-install/README.md)
4. 從 [02 AI 整理文獻](02-organize-data/README.md) 開始，依課程地圖往下做。階段五要另外開啟 `05-agent-skills/` 資料夾，見 [05-agent-skills/README.md](05-agent-skills/README.md)

需要：Windows 10/11 或 macOS、Google 帳號（登入 Antigravity）、GitHub 帳號（階段三起）；階段五需要模組三的 LaTeX（輸出 PDF）。
